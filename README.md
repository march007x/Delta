# Δ Delta

แพลตฟอร์มเรียนคณิตศาสตร์แบบโต้ตอบ ระดับ ม.4–ม.6 → มหาวิทยาลัย

> Δ คือสัญลักษณ์ของการเปลี่ยนแปลง ใช้ทั้งในแคลคูลัส (Δx → 0) และฟิสิกส์ (Δv, Δt)
> — และคือสิ่งที่เว็บนี้ตั้งใจทำกับผู้เรียน

---

## เริ่มใช้งาน

```bash
npm install
npm run dev        # เปิด http://localhost:3000
```

คำสั่งอื่น

```bash
npm run build      # สร้างเวอร์ชันสำหรับใช้งานจริง
npm start          # รันเวอร์ชันที่ build แล้ว
npm run typecheck  # ตรวจชนิดข้อมูลทั้งโปรเจกต์
npm run lint       # ตรวจสไตล์โค้ด
```

ไม่ต้องตั้งค่า environment variable ใด ๆ — เวอร์ชันนี้ยังไม่ต่อฐานข้อมูล

### หลักการที่ถือไว้ตลอด

1. **เนื้อหาไม่อยู่ในโค้ด** — บทเรียนทุกบทเป็นข้อมูลใน `src/content/` จึงย้ายไปฐานข้อมูลได้โดยไม่ต้องเขียนหน้าเว็บใหม่
2. **สีทุกสีมาจาก token เดียว** ใน `globals.css` — ไม่มีค่าสีเขียนตายตัวใน component
3. **สูตรเรนเดอร์ฝั่งเซิร์ฟเวอร์** — KaTeX ไม่ถูกส่งไปให้เบราว์เซอร์โหลด (หน้าบทเรียนใช้ JS 116 KB)
4. **กราฟวาดบน canvas ไม่ผ่าน React state** — ลากได้ลื่นและไม่ทำให้หน้าเว็บกระตุก
5. **ทุกกราฟมีตัวเลขกำกับเสมอ** และเลื่อนด้วยคีย์บอร์ดได้ ไม่ใช่ลากอย่างเดียว

## วิธีเพิ่มบทเรียนใหม่

1. สร้างไฟล์ใน `src/content/lessons/ชื่อบท.ts` ลอกโครงจาก `quadratic-function.ts`
2. เพิ่มหัวข้อใน `src/content/structure.ts` (พร้อมระบุ `prerequisites`)
3. เพิ่มบทเรียนเข้าอาร์เรย์ `RAW` ใน `src/content/index.ts`
4. `npm run build` — ถ้าโครงสร้างผิด zod จะฟ้องทันที

บล็อกเนื้อหาที่ใช้ได้: `paragraph` · `math` · `list` · `callout` · `viz` · `worked` · `quiz`
ในข้อความใช้ `$สูตร$` แทรกสูตร และ `**ข้อความ**` ทำตัวหนาได้

## วิธีเพิ่มกราฟใหม่

สร้าง component ใน `src/components/viz/` โดยประกอบจาก `VizCanvas` + `ParameterPanel` + `VizFrame`
แล้วลงทะเบียนชื่อไว้ใน `registry.tsx` — จากนั้นบทเรียนเรียกใช้ด้วย `componentKey` ได้เลย

## นำเว็บขึ้นออนไลน์ (ฟรี)

ใช้เวลาราว 15 นาที ไม่มีค่าใช้จ่าย และไม่ต้องใช้บัตรเครดิต

**1. อัปโหลดโค้ดขึ้น GitHub**

โปรเจกต์นี้มี git repo พร้อม commit แรกอยู่แล้ว เหลือแค่สร้าง repository เปล่าบน GitHub แล้ว

```bash
git remote add origin https://github.com/ชื่อผู้ใช้ของคุณ/delta.git
git push -u origin main
```

**2. เชื่อมกับ Vercel**

- เข้า vercel.com แล้วสมัครด้วยบัญชี GitHub
- กด Add New → Project แล้วเลือก repository นี้
- Vercel จะตรวจเจอว่าเป็น Next.js และตั้งค่าให้เองทั้งหมด — กด Deploy ได้เลย

**3. ตั้งที่อยู่เว็บ**

หลัง deploy ครั้งแรก Vercel จะให้ที่อยู่มา เช่น `delta-xxx.vercel.app`
กลับไปที่ Settings → Environment Variables ของโปรเจกต์ แล้วเพิ่ม

```
NEXT_PUBLIC_SITE_URL = https://ที่อยู่ที่ Vercel ให้มา
```

จากนั้นสั่ง Redeploy หนึ่งครั้ง เพื่อให้ `sitemap.xml` และลิงก์รูปตอนแชร์ชี้ไปที่อยู่จริง
(ถ้าข้ามขั้นนี้ เว็บยังใช้งานได้ปกติ แต่ Google จะเก็บหน้าเข้าดัชนีไม่ถูก และแชร์ลิงก์แล้วรูปจะไม่ขึ้น)

**4. หลัง deploy แล้ว**

- ส่ง `https://ที่อยู่ของคุณ/sitemap.xml` เข้า Google Search Console เพื่อให้คนค้นเจอ
- ทุกครั้งที่ `git push` Vercel จะ deploy ให้อัตโนมัติ ไม่ต้องทำอะไรเพิ่ม

### รูปสำหรับแชร์ลิงก์

`public/og.png` สร้างจากสคริปต์ `scripts/make-og.py` แก้ข้อความแล้วสร้างใหม่ได้ด้วย

```bash
python3 scripts/make-og.py
```

สคริปต์จะหาฟอนต์ไทยในเครื่องให้เอง ถ้าไม่เจอจะใช้ข้อความภาษาอังกฤษแทน

## แผนเฟสถัดไป

- **Phase 3** คลังโจทย์แยกจากบทเรียน + ระบบใบ้ + เฉลยละเอียด
- **Phase 4** ฐานข้อมูล Supabase + ระบบบัญชีผู้ใช้ (ย้าย `repo/content.ts` และ `progress/store.ts`)
- **Phase 5** ระบบสอบจับเวลา + วิเคราะห์จุดอ่อนจากกราฟพื้นฐาน
- **Phase 6** หน้าแอดมินสำหรับเพิ่มเนื้อหาโดยไม่ต้องแตะโค้ด
- **ภายหลัง** เนื้อหาฟิสิกส์ ซึ่งใช้เครื่องมือวาดกราฟชุดเดียวกันได้ทันที

## เรื่องโจทย์และลิขสิทธิ์

โจทย์ทุกข้อในโปรเจกต์นี้เขียนขึ้นใหม่ โดยอ้างอิงผังข้อสอบและขอบเขตเนื้อหาที่เผยแพร่สาธารณะ
**ไม่มีการนำข้อสอบจริงจากสนามสอบใดมาเผยแพร่ซ้ำ** และจะไม่เรียกโจทย์ที่เราแต่งเองว่าเป็น "ข้อสอบจริง"
โครงสร้างฐานข้อมูลในเฟสถัดไปมีฟิลด์ `origin` และ `license_status` เพื่อบังคับเรื่องนี้ในระดับระบบ
